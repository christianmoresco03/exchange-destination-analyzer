# Exchange Destination Analyzer

A data-driven decision-support tool designed to compare and rank international exchange destinations based on academic quality, career opportunities, cost of living, safety and lifestyle factors.

## Project Overview

Choosing an exchange destination involves balancing multiple academic, professional and personal factors. This project aims to transform that decision into a structured and transparent multi-criteria analysis.

The tool will combine external quantitative data with user-defined preferences to generate a customized ranking of potential exchange destinations.

## Key Factors

The model will evaluate destinations across several dimensions:

* **Academic Quality** – university reputation and international rankings
* **Career Opportunities** – attractiveness of the local professional and business environment
* **Cost of Living** – relative affordability of each destination
* **Safety** – safety and risk indicators
* **Lifestyle & City Attractiveness** – overall quality and attractiveness of the destination

## Methodology

Each destination will receive standardized scores across the selected criteria.

Users will be able to assign different weights to each factor according to their personal priorities.

The final ranking will be calculated using a weighted multi-criteria scoring model.

## Data Sources

The analysis will rely primarily on reputable external sources, potentially including:

* QS World University Rankings
* Financial Times rankings
* Statista
* Public economic and safety datasets
* Additional institutional and international data sources

Exact sources and variables will be documented as the project develops.

## Planned Features

* Interactive destination comparison
* Customizable criterion weights
* Automated destination ranking
* Data visualizations
* Transparent scoring methodology
* Interactive web interface

## Technology

The project will be developed in Python and will progressively incorporate data analysis and web application tools.

## Project Status

**Currently under development.**

The first stage focuses on defining the methodology, collecting reliable datasets and building the scoring model.
